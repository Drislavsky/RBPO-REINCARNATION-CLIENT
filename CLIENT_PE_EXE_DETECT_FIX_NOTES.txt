Fix: PE detection balance.

Object type detection in the Windows service now uses:
- .txt/.bat/.cmd/.script/.js/.py/.ps1/.vbs/.wsf/.hta => SCRIPT
- .exe/.dll/.sys/.scr => PE
- no trusted extension + MZ header => PE fallback
- everything else => Any/unknown

This keeps PE signatures inside TXT/BAT/SCRIPT files from being detected as PE,
but restores detection for lab .exe test files, including tiny artificial .exe
files that contain only a test signature and do not have a full PE structure.

Server MIME/fileType parsing also recognizes common PE MIME strings such as
application/x-msdownload and application/x-dosexec.
