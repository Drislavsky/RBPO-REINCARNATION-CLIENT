IMPORTANT

This version removes all hardcoded demo AV signatures from the client/service path.
The Windows service downloads the AV database only from the server endpoint:

  GET https://localhost:8443/api/signatures

The in-memory database is refreshed:
1) after successful license activation;
2) when the GUI button "Инфо баз" is pressed;
3) immediately before scanning a file or directory.

After replacing the project, rebuild BOTH server and client/service.
Reinstall the Windows service because BMTXService.exe changed.
