Client-only scan fix.

Reason previous build returned CLEAN:
- Server /api/signatures returns firstBytesHex + remainderHashHex + remainderLength.
- remainderHashHex is SHA-256 of bytes AFTER firstBytesHex.
- remainderLength is the length AFTER firstBytesHex.
- Previous client treated remainderLength as full signature length and hashed the whole signature from current position.

Fixed in src/service.cpp:
- ObjectSignatureLength is now firstBytesHex.length/2 + remainderLength.
- Scanner compares firstBytesHex at scan position, then hashes only the remainder and compares it with remainderHashHex.
- Server fileType values like text/plain/application/octet-stream are handled client-side without changing the server.
- No local demo signatures are added.
